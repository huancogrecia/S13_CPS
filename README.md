# S13_CPS

Proyecto Java con Maven para practicar integración continua con Jenkins.

## Pipeline

El `Jenkinsfile` ejecuta las etapas de checkout, compilación, pruebas unitarias y empaquetado.

## Requisitos

- Java 21
- Maven
- Jenkins con las herramientas JDK `Java` y Maven `Maven` configuradas

## Ejecución local

```bash
mvn clean test
```
